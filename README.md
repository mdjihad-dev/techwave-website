# TechWave

TechWave is a responsive podcast-style landing page focused on technology, productivity, and personal growth. The interface was built with a strong focus on visual hierarchy, responsive layout, and modern utility-first styling.

## Tech Stack

- HTML5
- Tailwind CSS
- CSS
- Font Awesome

## Highlights

- Responsive navigation
- Podcast-focused hero section
- Call-to-action buttons
- Responsive content sections
- Utility-first styling with Tailwind CSS

## Getting Started

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/mdjihad-dev/techwave-website.git
cd techwave-website
```

## Project Focus

This project helped me practice responsive layouts, Tailwind CSS utilities, component-like page sections, and translating a modern visual design into a functional frontend.
